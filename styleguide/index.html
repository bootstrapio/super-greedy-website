Section Headers

One universal section contract.

Every section uses one Header, one Content track, and optional Media across three swappable layouts.

  • Header

    One shared Header partial.

    Header owns the Label, Heading, Lead, and optional Button. Every section resolves the same semantic partial, heading level, alignment variant, and shared Typography roles; hero emphasis remains structured content, not page-local markup.

  • Content

    One reusable Content track.

    Content follows the Header in the layout track and can own an optional Label, Title, Paragraph, Button, and Badge. Lists, cards, banners, Accordions, Tabs, and carousels reuse these roles instead of inventing section-specific copy markup.

  • Media

    One shared Media frame.

    Media is an optional sibling slot for an image, video, or SVG. marketingShowcaseFrame owns the shared border, radius, clipping, alignment, intrinsic ratio, and responsive bounds so every section uses the same surface.

Tabs Component

Switch between related views without leaving the page.

Tabs are a reusable Content component with vertical and horizontal orientations; each tab uses the same media and copy in both. Horizontal Tabs place media above a centered tablist and selected copy below. Active horizontal tabs center in the row when the scroll range allows. Vertical Tabs put selected copy beneath its tab title beside the full-size, full-bleed media: a 1fr/2fr split at large widths, half columns at medium widths, then the horizontal layout at the smallest size. Long vertical tab titles truncate to their column above the smallest breakpoint.

The carousel uses the universal Header/Content section wrapper, canonical featureCard items, shared badges and controls, and a section-aligned card-track breakout resolved before first paint while the Header stays aligned to the shell; its component template and stylesheet are the sole carousel owners.
