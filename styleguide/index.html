Sections, cards, navigation, and responsive layouts draw from the same spacing, shell, radius, and border tokens instead of one-off values.

  • section-layout.cssfull / half / one-thirdCanonical layout variant owner.
  • --spacevar(--space)Base spacing unit.
  • --marketing-shell-widthvar(--marketing-shell-width)Desktop content width.
  • splitLayout--fullminmax(0, 1fr)Full-width single-column layout.
  • splitLayout--halfrepeat(2, minmax(0, 1fr))Two equal layout columns.
  • splitLayout--one-thirdminmax(0, 2fr) minmax(0, 1fr)Two-column layout with a one-third secondary column.
  • --marketing-border-radiusvar(--marketing-border-radius)Shared card, panel, badge, and CTA radius.

Motion

Motion has a shared owner and a reduced-motion rule.

CTA icons, the pricing arrow, chart illustration, and embedded account values use named stylesheet animations. Reduced-motion preferences remove continuous movement where the component owns it.

  • chartBarInchartBarInChart bar reveal.
  • chartDotInchartDotInChart signal reveal.
  • chartDotPulsechartDotPulseChart signal pulse.
  • chartLevelInchartLevelInChart level reveal.
  • gbMktValueTickgbMktValueTickEmbedded Platform value ticker.

The reduced-motion media rule disables the embedded value ticker; the chart and CTA motion remains declarative and finite or can be removed by the browser preference.
