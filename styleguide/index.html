One structure, one token set, four reusable layouts.

  • Structure

    One semantic header contract.

    Every marketing section receives one shared header with one Label, one context-correct Heading, and one paragraph Lead as direct children. Production templates provide only the section shell and shared marker.

  • Layout

    One responsive spacing rhythm.

    Label to Heading uses 0.5 × --space. Heading to Lead uses 1.5 × --space. Headers, cards, lists, and banners reuse these Styleguide-owned values.

  • Element

    Three roles, one owner.

    Label, Heading, and Lead resolve through fieldLabel, typography-title, and typography-lead. Their type scale and measure remain owned by the Typography and Header Styleguide stylesheets.

Layout

Spacing and shape use shared geometry.

Sections, cards, navigation, and responsive layouts draw from the same spacing, shell, radius, and border tokens instead of one-off values.

  • section-layout.cssfull / half / thirdCanonical layout variant owner.
  • --spacevar(--space)Base spacing unit owned by section-layout.css.
  • --stepper-marker-sizevar(--stepper-marker-size)Stepper marker diameter derived from the base spacing unit.
  • --marketing-shell-widthvar(--marketing-shell-width)Desktop content width.
  • marketingShowcaseFrameshared media wrapperCanonical wrapper for every rendered content media surface; media surfaces use the shared style--border geometry.
  • --marketing-media-max-widthvar(--marketing-media-max-width)Maximum width for every shared marketing media surface.
  • --marketing-media-max-heightvar(--marketing-media-max-height)Maximum height for every shared marketing media surface; intrinsic ratios are preserved within the bound.
  • layout--fullminmax(0, 1fr)Full-width single-column layout.
  • layout--halfrepeat(2, minmax(0, 1fr))Two equal layout columns.
  • layout--thirdminmax(0, 2fr) minmax(0, 1fr)Two-column layout with a one-third secondary column.
  • style--border--style--border-radius, --style--border-width, --style--border-styleShared border contract owned by section-layout.css.

Motion

Motion has a shared owner and a reduced-motion rule.

CTA icons, chart illustration, and embedded account values use named stylesheet animations. Reduced-motion preferences remove continuous movement where the component owns it.

  • chartBarInchartBarInChart bar reveal.
  • chartDotInchartDotInChart signal reveal.
  • chartDotPulsechartDotPulseChart signal pulse.
  • chartLevelInchartLevelInChart level reveal.
  • gbMktValueTickgbMktValueTickEmbedded Platform value ticker.

The reduced-motion media rule disables the embedded value ticker; the chart and CTA motion remains declarative and finite or can be removed by the browser preference.
