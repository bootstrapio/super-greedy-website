List

Vertical and horizontal lists share one structure.

Both layouts use the same optional Label, Title, and Paragraph item contract; only the list direction changes.

Vertical List
  • Overview

    Stack related content in a clear sequence.

    Use a vertical flow when each item should receive the reader's full attention.

  • Details

    Keep the same item structure throughout.

    Each item follows the shared Label, Title, and Paragraph order; fields remain optional in the contract.

  • Actions

    Move from explanation to the next step.

    The final item closes the sequence while retaining the same shared spacing and roles.

Horizontal List
  • Overview

    Place related content side by side.

    Use a horizontal flow when the items should be compared at a glance.

  • Details

    Preserve the same shared copy roles.

    The orientation changes the arrangement, not the optional Label, Title, and Paragraph contract.

  • Actions

    Keep each item independently readable.

    Shared item spacing and typography keep the horizontal layout consistent with the vertical one.

Motion

Motion has a shared owner and a reduced-motion rule.

CTA icons, the pricing arrow, chart illustration, and embedded account values use named stylesheet animations. Reduced-motion preferences remove continuous movement where the component owns it.

  • cta-icon-spincta-icon-spinPrimary CTA icon rotation.
