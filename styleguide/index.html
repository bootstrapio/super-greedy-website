Section Headers

One universal section contract.

Every section uses one Header, one Content track, and optional Media across three swappable layouts.

  • Header

    One shared Header partial.

    Header owns the Label, Heading, Lead, and optional Button. Every section resolves the same semantic partial, heading level, alignment variant, and shared Typography roles; hero emphasis remains structured content, not page-local markup.

  • Content

    One reusable Content track.

    Content follows the Header in the layout track and can own an optional Label, Title, Paragraph, Button, and Badge. Lists, cards, banners, accordions, and carousels reuse these roles instead of inventing section-specific copy markup.

  • Media

    One shared Media frame.

    Media is an optional sibling slot for an image, video, or SVG. marketingShowcaseFrame owns clipping, radius, alignment, intrinsic ratio, and responsive bounds so every section uses the same surface.

Layout

Spacing and shape use shared geometry.

Header, Content, and optional Media compose through one sectionLayout owner; full, half, and third can swap without changing the content contract.

  • sectionLayoutHeader + Content track + optional MediaUniversal section composition owned by the shared layout wrapper; Header-to-Content and Content-to-Media separation use 4 × --space, split Content/Media tracks stay vertically centered, and non-reversed Media frames start at the Media track.
  • section-layout.cssfull / half / thirdCanonical manifest-driven layout variant owner; third layouts use the declared split ratio above 880px, become Half through 720px, then become Full at the smallest size.
  • --spacevar(--space)Base spacing unit owned by section-layout.css.
  • --stepper-marker-sizevar(--stepper-marker-size)Stepper marker diameter derived from the base spacing unit.
  • --marketing-shell-widthvar(--marketing-shell-width)Desktop content width.
  • --marketing-bar-heightvar(--marketing-bar-height)Shared header and footer bar height.
  • marketingShowcaseFrameshared media wrapperCanonical wrapper for every rendered media surface; owns clipping, radius, alignment, responsive media bounds, and full-frame raster media fill.
  • --marketing-media-max-widthvar(--marketing-media-max-width)Maximum width for every shared marketing media surface.
  • --marketing-media-max-heightvar(--marketing-media-max-height)Maximum height for full-layout media at the shared 2:1 ratio.
  • --marketing-media-aspect-ratiovar(--marketing-media-aspect-ratio)Shared 2:1 ratio for every full-layout media frame.
  • --marketing-platform-card-min-widthvar(--marketing-platform-card-min-width)Minimum width for the contained Platform Card preview.
  • --marketing-platform-card-max-widthvar(--marketing-platform-card-max-width)Maximum width for the contained Platform Card preview and its shared frame.
  • marketingPreviewCard responsive scalecontainer-relative width, height, and contentThe contained Platform Card scales its bands, insets, typography, gaps, and status dot from the shared frame width; full-layout media uses the shared 1120px maximum and 2:1 frame ratio.
  • layout--fullminmax(0, 1fr)Single-column layout that centers the Header/Content track and contains centered Media inside the section boundary.
  • layout--halfrepeat(2, minmax(0, 1fr))Two equal columns that keep the Header/Content track and Media on the same shared geometry.
  • layout--thirdminmax(0, 1fr) minmax(0, 2fr)Two-column Content/Media layout with a one-third Content track and two-thirds Media track.
  • --marketing-layout-wide-narrow-columnsminmax(0, 2fr) minmax(0, 1fr)Shared wide/narrow geometry for reversed Media/Content sections.
  • layout--reversedoptional two-column modifierSwaps the canonical split columns without changing Header, Content, or Media markup.
  • sectionMedia--bleedmanifest opt-in media modifierAllows only explicitly declared split Media surfaces to break out toward the viewport edge; omitted media remains contained in its assigned track.
  • sectionLayout--header-fullHeader row + Media/Content rowsShared composition used by list and workflow sections: Header spans the layout, then Media and Content occupy the following rows or centered split tracks according to the selected full, half, or third layout. Full-layout Media fills the track inside the shared 1120px maximum and 2:1 frame, while figure captions stack below it.
  • sectionContentBodyContent body stackCanonical wrapper for list and workflow Content items; preserves the shared 4 × --space internal stack while Header and Media are laid out independently.
  • data-section-slotheader / content / mediaShared slot markers; Header, Content, and optional Media compose through the universal section layout contract.
  • workflow-timelinelayout--full/layout--third + sectionLayout--header-full + manifest-driven StepperSequential workflow sections use a full-width Header, then Media and Content in the selected layout; the Home workflow uses a horizontal Stepper, while ORB uses the vertical split variant.
  • style--border--style--border-radius, --style--border-width, --style--border-styleShared border contract owned by section-layout.css.
