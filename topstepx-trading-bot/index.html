A trading bot built for TopStepX. Rules first. Execution second.

Super Greedy connects to your TopStepX account through the ProjectX API and runs one configured futures strategy inside the sessions, bias, contracts, timeframes, and risk limits you choose.

Get Started with TopStepX
TopStepX API Setup

Get your API key and connect the bot.

TopStepX API Access is a separate ProjectX subscription. Complete the platform setup first, then enter your TopStepX username and API key in Super Greedy.

  1. 01

    Create or open your ProjectX Dashboard account.

    Go to the ProjectX Dashboard and sign in or register before subscribing to API Access.

    Open ProjectX Dashboard
  2. 02

    Subscribe to ProjectX API Access.

    In ProjectX Dashboard, open Subscriptions → ProjectX API Access. The subscription is $29/month; enter promo code topstep for 50% off, bringing the API subscription to $14.50/month when eligible. Confirm the discount at checkout.

    View official API access guide
  3. 03

    Link the subscription to your TopStepX profile.

    In TopStepX, open Settings → API, choose Add Link, and confirm the connection to the ProjectX Dashboard. The subscription must be linked before you can create a key.

  4. 04

    Generate your TopStepX API key.

    In TopStepX Settings → API, choose Add API Key and copy the key somewhere secure. Use your platform username when connecting; it is not your email address or trading account ID.

    Open TopStepX API settings
  5. 05

    Test the credentials in Super Greedy.

    Open Settings → Platforms → TopStepX, enter your username and API key, click Test, then Save. After the account loads, select the account and configure your strategy, contracts, sessions, and risk limits.

TopStepX Trading Bot FAQ

Questions about automated TopStepX trading.

Straight answers about the connection, automation, supported futures workflow, and risk controls.

What is a TopStepX trading bot?

A TopStepX trading bot is software that connects to a TopStepX account, evaluates configured market rules, and manages eligible orders automatically. Super Greedy runs your selected futures strategy inside the limits you configure.

Does Super Greedy connect to TopStepX?

Yes. Super Greedy connects to your TopStepX account and uses the configured account, futures charts, strategy rules, and risk limits as the basis for automated trade management.

How do I get TopStepX API access?

Create or open a ProjectX Dashboard account, subscribe to ProjectX API Access, and use promo code topstep for 50% off the $29/month API subscription when eligible. Then link the subscription to your TopStepX profile under Settings → API before generating your API key.

Where do I find my TopStepX API key?

After your ProjectX API subscription is linked, open TopStepX Settings → API and choose Add API Key. Copy the key securely. It grants trading access to eligible accounts, so never share it or commit it to a public repository.

How do I connect my TopStepX API key to Super Greedy?

Open Super Greedy Settings → Platforms → TopStepX, enter your TopStepX platform username and API key, click Test, and then Save. The platform username is not your email address or trading account ID.

What does Super Greedy automate on TopStepX?

Super Greedy watches configured futures charts, checks the selected setup against your sessions and bias, submits eligible entries with protective orders attached, and manages the position through the exit.

Which futures contracts can I trade with the TopStepX bot?

Super Greedy currently supports ES, NQ, MES, and MNQ futures, depending on the contracts available through your TopStepX account and setup.

Can I control the TopStepX bot's risk settings?

Yes. You configure sessions, directional bias, contracts, timeframe, exit type, and maximum stop loss before the bot evaluates and manages trades.

Does the TopStepX trading bot guarantee profits?

No. Super Greedy automates the rules you configure, but no trading system guarantees profits. You remain responsible for reviewing platform requirements and managing your trading risk.
